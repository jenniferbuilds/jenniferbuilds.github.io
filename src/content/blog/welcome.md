Welcome to my blog! This is the very first post, and it doubles as a feature test.

## Why I built this blog

I've always wanted a little corner of the internet to record study notes, project experiences, and random thoughts. This blog is built with [Astro](https://astro.build), open-sourced on GitHub, and automatically deployed to GitHub Pages via GitHub Actions — completely free, and blazing fast.

## What this blog offers

- **Markdown writing**: every post is a Markdown file under `src/content/blog/`
- **Dark mode**: toggle it in the top-right corner; your choice is remembered
- **Full-text search**: powered by Pagefind, with the index generated at build time
- **Tags & categories**: easy ways to organize and browse posts

Blogging means writing a lot of Markdown, so here's a cheatsheet of the syntax I use most.

## Headings & emphasis

```markdown
## Second-level heading
### Third-level heading

**Bold** and *italic*
```

Result: **Bold** and *italic*

## Lists

```markdown
- An unordered item
- Another item

1. An ordered item
2. Another item
```

## Code

Inline code: `console.log('hello')`

Code block:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

## Quotes & tables

> This is a blockquote. Great for callouts, tips, or notes.

| Syntax  | Result       |
| ------- | ------------ |
| `**x**` | Bold         |
| `` `x` `` | Inline code |

For more, check out the [Markdown Guide](https://www.markdownguide.org/).
